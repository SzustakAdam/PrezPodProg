# Skrócony słownik techniczny

    user - użytkownik aplikacji

    record - wpis,
        np. wpis w bazie danych,
        zbiór informacji

    table - tabela,
        dane tabelaryczne w excelu,
        zbiór danych w bazie danych

    field - pole,
        np. pole do wprowadzania tekstu

    form - formularz,
        np. formularz rejestracji nowego użytkownika w aplikacji

    list - lista

    group - grupa,
        np. grupa użytkowników

    role - rola,
        np. rola użytkownika albo grupy

    application - aplikacja / program

    module - moduł,
        fragment kodu aplikacji

    incident - zdarzenie np. zgłoszenie serwisowe

    request - żądanie / wniosek np. 

    change - zmiana

    script - skrypt,
        kod programu w języku skryptowym
        tj. JavaScript / Python

    flow - przebieg,
        sposób działania programu,
        przebieg zdażeń w procesie

    error - błąd programu

    log - zapisywanie informacji dla developerów
        przez aplikację,
        np. informacje o błędach
